# জোনাকি মোবাইল (Jonaki Mobile)

বাংলাদেশি প্রিপেইড টেলিকম অ্যাপের একটি ডেমো। ব্যাকএন্ড নেই: **GitHub রিপোজিটরিই সার্ভার ও ডাটাবেজ**। ফ্রন্টএন্ড GitHub Pages থেকে চলে, আর প্রতিটি ডেটা পরিবর্তন রিপোজিটরিতে একটি git commit হয়ে যায়।

ডিজাইন: ম্যাট ব্ল্যাক ব্যাকগ্রাউন্ড, ফ্রস্টেড গ্লাস কার্ড, অ্যাম্বার অ্যাকসেন্ট।

## ফিচার

- নম্বর ও ৪ সংখ্যার পিন দিয়ে লগইন, নতুন অ্যাকাউন্ট খোলা
- ব্যালেন্স, মেয়াদ, ইন্টারনেট/মিনিট/এসএমএস ব্যবহারের রিং
- রিচার্জ (নিজের বা অন্য জোনাকি নম্বরে), ২০০ টাকা বা বেশিতে ১০% বোনাস
- ইন্টারনেট, মিনিট ও কম্বো প্যাক কেনা
- লেনদেনের ইতিহাস
- প্রোফাইল পেজ থেকে GitHub সংযোগ সেটআপ

## ডেটা কীভাবে সংরক্ষণ হয়

```
data/
  config.json        অ্যাপের সেটিংস (রিচার্জ সীমা, মাধ্যম)
  packages.json      প্যাকেজের তালিকা ও দাম
  offers.json        অফার
  users/<নম্বর>.json  প্রতি গ্রাহকের একটি ফাইল (ব্যালেন্স, ব্যবহার, লেনদেন)
```

অ্যাপ GitHub Contents API দিয়ে ফাইল পড়ে ও লেখে। দুজন একসঙ্গে লিখলে `sha` মিলে না, তখন অ্যাপ নতুন করে পড়ে আবার চেষ্টা করে (৩ বার পর্যন্ত)।

| মোড | কখন | কী হয় |
|---|---|---|
| লাইভ | প্রোফাইলে টোকেন দেওয়া আছে | প্রতিটি লেনদেন রিপোজিটরিতে commit হয় |
| ডেমো | টোকেন নেই | পড়া হয় স্ট্যাটিক ফাইল থেকে, লেখা থাকে শুধু ওই ব্রাউজারে |

## সেটআপ (৫ ধাপ)

1. GitHub-এ নতুন রিপোজিটরি খুলুন, যেমন `jonaki-mobile`।
2. এই ফোল্ডারের সব ফাইল আপলোড করুন:
   ```bash
   git init && git add . && git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<আপনার-ইউজারনেম>/jonaki-mobile.git
   git push -u origin main
   ```
3. রিপোজিটরির **Settings → Pages → Source** এ **GitHub Actions** বাছুন। `.github/workflows/pages.yml` নিজে থেকে ডিপ্লয় করবে।
4. সাইটের ঠিকানা হবে `https://<ইউজারনেম>.github.io/jonaki-mobile/`।
5. লাইভ মোডের জন্য একটি **fine-grained personal access token** বানান:
   GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens →
   শুধু এই রিপোজিটরি বাছুন, **Repository permissions → Contents: Read and write** দিন।
   অ্যাপে **প্রোফাইল → GitHub ডাটাবেজ**-এ টোকেন বসিয়ে **সেভ** ও **পরীক্ষা** চাপুন।

ডেমো লগইন: `01712345678` / পিন `1234`, আরেকটি `01812000111` / পিন `4321`।

লোকালে চালাতে (ফাইল সরাসরি খুললে চলবে না):

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## নিরাপত্তা: জেনে রাখুন

এটি শেখা ও ডেমোর জন্য। সত্যিকারের গ্রাহক বা টাকার জন্য **ব্যবহার করবেন না**।

- রিপোজিটরি পাবলিক হলে `data/users/*.json` সবাই পড়তে পারে, পিনের হ্যাশসহ। ৪ সংখ্যার পিন হ্যাশ থেকে সহজে বের করা যায়।
- যার ব্রাউজারে টোকেন আছে, সে রিপোজিটরির যেকোনো ডেটা বদলাতে পারে। ব্যালেন্সও।
- লগইন ও ব্যালেন্সের হিসাব ব্রাউজারেই হয়, তাই সার্ভারে কোনো যাচাই নেই।
- বিকাশ/নগদ/রকেট পেমেন্ট সিমুলেটেড। আসল পেমেন্টের জন্য মার্চেন্ট API ও নিজস্ব সার্ভার লাগবে।
- GitHub API-র সীমা আছে (টোকেনসহ ঘণ্টায় ৫,০০০ রিকোয়েস্ট), আর প্রতিটি লেনদেন একটি commit।

প্রোডাকশনের পথ: একটি ব্যাকএন্ড (Node/Go + PostgreSQL), সার্ভারে যাচাই ও bcrypt/argon2 পিন, এবং লাইসেন্সপ্রাপ্ত পেমেন্ট গেটওয়ে।

```
js/util.js            ফরম্যাট ও হ্যাশ সহায়ক
data/                 ডাটাবেজ ফাইল
manifest.json         হোম স্ক্রিনে যোগ করার জন্য
.github/workflows/    GitHub Pages ডিপ্লয়
```
